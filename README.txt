MK Earnings Demo — APK-ready package

- android/MKEarningsDemo: Android Studio project for User APK
- assets/user.html: existing safe-upgrade user app
- assets/admin.html: existing safe-upgrade admin page kept in the project for reference
- backend: use the backend from MK_Earnings_MultiDevice_Upgrade.zip
- BUILD_APK.md: APK build instructions

No existing localStorage data is intentionally cleared by this package. This is a demo-only virtual wallet/game package; it does not implement real-money deposits or payouts.
